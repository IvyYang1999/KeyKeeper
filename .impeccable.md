## Design Context

### Users
People using AI coding tools, including non-programmers, who want to store API keys
and deliberately delegate selected website access without exposing authentication
values in chat. Chinese-first copy must explain actions without developer knowledge.

### Brand Personality
Simple, reassuring, system-native. Explicitly confirmed by the product owner on
2026-09-11 for the Chrome extension and its relationship to the existing macOS App.

### Aesthetic Direction
Continue KeyKeeper's restrained macOS utility style: native controls, readable text,
few options and no decorative dashboard. Chinese labels first; supported English UI
remains available. No new visual brand direction is introduced by this feature.

### Design Principles
- State which website is selected, who requests access, and how to withdraw it.
- Explain that delegated login permits account actions, not merely read access.
- Never show authentication values as a convenience preview.
- A confirmation is not success: report verified completion or a precise limitation.
- Keep controls accessible, scrollable and predictable; system-native typography and
  focus behavior take precedence over decorative brand styling.
