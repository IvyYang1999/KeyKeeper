## 实现与候选验收

- BrowserSessionManagerView 无论有无会话都展示两条来源；Chrome 未登记可展开设置，已登记给出导入步骤，缺扩展如实提示。没有自动注册/安装。
- 访问/变更分标签，默认访问；切换记录类型从顶部开始。列表在查看详情时仍挂载，窄窗口返回保持原位置；宽窗口右侧详情，切换记录重置详情滚动，Escape 返回。
- 使用权限按真实 subject 分组，同名不同身份、无法识别的身份不会混合。每条授权独立下钻、确认和按 ID 撤销，读取失败不显示有效、不开放撤销，且停止定时重试。
- 访问详情保留真实条目，不把合并数包装成总使用次数。批准使用记录的字段范围保留结构，不能把 `[a,b]` 与单个 `a, b` 字段混淆；当前权限与历史结果分开。
- 页面“查看凭据”经主窗口已有 router 定位，兼容旧 ID alias；目标不存在不制造死链接。新增文案有中文与占位符门禁。

## known_limits

- 既有授权仅留最近使用，撤掉授权后其 last-use 投影也消失；后台最多 500、元数据变更最多 200。这不是完整、持久、逐次审计，本批不新增审计存储。
- 理由和命令来自调用方、可能已截短；只遮盖常见敏感参数，不能识别任意无标签/编码秘密，也不重建完整命令。未留存的备注正文、旧值不补造。
- 访问审计无终端会话上下文，不借用其他终端的授权来推断当前权限；授权详情仍展示原授权的有效期/范围。
- 不保证跨记录类型保留滚动；仅详情返回保留。没有新增横向滚动区域，长文本换行；键盘 Tab 的系统全键盘导航开关未改动。
- 这批未更改存储、Core/IPC、实际授权策略、供应商或整体 UI 设计。尚未安装/重启正式 App，未经确认不部署；本地验收不等于公开发版。
