# Provider 浏览入口 · 本批边界

- 基线：`5a8c733`；仅 App 展示/选择层，不修改 Core 凭据合同、密钥、存储格式或 CLI。
- 必达：113 项可搜索（名称/ID/别名）、可分类；每行复用已核实官方图标，无资产时字母回退；地区/套餐保持可辨；详情在主窗口及菜单栏均可打开对应官方管理入口。
- 兼容：打开/搜索/取消不写入，只有显式选中才沿用现有 provider 绑定操作；旧 alias 只规范化显示；未知 ID 保留原值且不猜链接。跳转仅使用内置静态 HTTPS URL，不拼凭据或用户输入。
- 不做：新增供应商/官方资产采购、模板字段自动迁移、账户自动登录、逐家后台在线认证、官网或正式发布。
- 阻断：秘密泄漏/错误写入/丢失、启动/核心功能失败、旧绑定兼容失败、本批搜索分类链接或真实 UI 验收失败；其他优化进入 follow-up。
- 收口：先定向红绿测试 → 完成独立 UI 组件 → 真实接线回看（搜索、筛选、选择/取消、滚动、浅/深色）→ 一次全量门禁 → 提交 → 签名隔离 E2E → 无未保存表单时可回滚本机安装 → 交接。

## 已验证的实现与限制

- 分类为 AI 模型、AI 聚合与网关、云平台与数据库、开发与发布、Apple 服务、分析与监控、邮件与消息、支付；全目录唯一分区门禁会发现未来未分类项。
- 搜索认名称、ID、别名，忽略大小写/全半角，支持多个词同时匹配。弹层固定尺寸，列表滚动；打开定位当前项，取消不写，点击或回车才选择。
- 真机发现 SwiftUI 外层 `onMoveCommand` 收不到编辑中的方向键，改用原生 `NSSearchField` 字段编辑委托；真实测试已确认下移一次后回车选第二项。保留输入法组字处理，不保存搜索历史。接口参考：[Apple NSTextFieldDelegate](https://developer.apple.com/documentation/appkit/nstextfielddelegate)。
- 真实 App（独立数据、钥匙串与 socket）已验证：别名搜索、分类、空结果回车无写入、Esc 保持绑定、显式选择、详情链接随绑定更新。App Store Connect 链接实际打开官方登录页；没有登录或读页面秘密，不声称已认证后台。
- 浅/深色完整选择器与链接合成图已人工回看；复用现有官方资产，没有新增/修改 logo。无官方资产仍显示字母。
- 后台优先用已有 `rotateURL`（只是跳页，绝不执行轮换），否则已有官方取钥入口。GA4 和 Search Console 转到产品后台，AWS STS 转到控制台，Installer 证书转到证书列表。
- [AWS 控制台](https://console.aws.amazon.com/console/home)、[GA4](https://analytics.google.com/analytics/web/)、[Search Console](https://search.google.com/search-console) 的公开入口已核对；Apple 证书列表要求登录。部分供应商仍只提供登录/控制台入口，无法不经登录直接定位到当前账号的具体 key；不拼接用户账号或项目 ID。
- 未增加自动登录、远端账号验证、字段转换，也未修改 Core 或 CLI 合同。主窗口实际交互与共用组件浅/深色已验；菜单栏的共用入口尚需最终安装后 smoke。
