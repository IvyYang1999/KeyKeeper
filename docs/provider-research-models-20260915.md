Documentation examples are not treated as stable key grammars. No credential was read or called.

## Implementation decisions

- Split Bedrock short-term and long-term. Their issuers, production guidance, expiry, permissions inheritance, and Region behavior are materially different. Store `aws-region` as explicit public context; never derive or inject a Base URL from it.
- Split Qianfan CN, International, and Token 福利包 routes. The international endpoint is official, but account/key portability is not. Token 福利包 uses general Qianfan authentication; its integration env is an alias for that one value. Coding Plan is outside this catalog and must remain separate.
- Split NVIDIA API Catalog and NGC. `NVIDIA_API_KEY` routes hosted inference; `NGC_API_KEY` routes NGC CLI/catalog/registry. Accepting one in the other template would save a valid credential under the wrong operational contract. Keep API Catalog `shownOnce=false`: the first-party wording is conditional (the full secret may not be readable later), so require immediate copying without claiming guaranteed one-time display.
- Split ModelScope CN and Global. CN keeps `MODELSCOPE_API_TOKEN`, `MODELSCOPE_API_KEY`, and the official LangChain integration's `MODELSCOPE_SDK_TOKEN` as aliases of one secret. Global keeps only the two variables established for that site; the CN SDK alias is not inferred across domains.
- Split StepFun standard and Step Plan because Step Plan has a dedicated subscription, entitlement/key flow, quota, and billing contract. Do not split their routes: the official overview and quickstart explicitly use the same OpenAI/Anthropic-compatible API paths without an extra prefix.
- Split MiMo pay-as-you-go from Token Plan, and split Token Plan by cluster. MiMo explicitly documents different key families and one-time display for Token Plan. Cluster is also retained as explicit public context and does not drive automatic injection.
- LongCat is encoded because its key issuer, routes, and one-time display are closed. `LONGCAT_API_KEY` is explicitly labeled a KeyKeeper-local injection name, not an official LongCat default; it has no env aliases or automatic-client claim.
- No reviewed entry receives an online `validation`: a read endpoint and its permission/error semantics were not jointly established, so a 401/403 probe could mislabel a real but insufficiently privileged or plan-mismatched key as invalid.
