# KeyKeeper 0.3.8

## 中文

- 升级时，KeyKeeper 使用只读迁移服务，将早期版本保存的数据复制到新的受保护存储。
- 如果你从 0.3.6 或更早版本升级，先在新版中核对需要的凭据和网站登录态。然后可在「设置 › 开发者 › 0.3.7 之前的旧副本」查看旧条目名称，并打开「钥匙串访问」自行处理。遇到同名备份，或无法确定某条是否已经复制时，请保留该条目。首次安装无需清理。

## English

- KeyKeeper now uses a read-only migration service to copy data from earlier versions into protected storage.
- If you upgraded from 0.3.6 or earlier, first check the credentials and website sessions you need in the current app. In Settings › Developer › Copy from before 0.3.7, you can review legacy item names and open Keychain Access. Keep any duplicate or item you cannot confirm was copied. A fresh install requires no cleanup.
