# KeyKeeper 0.3.7

## 中文

- 可选 iCloud 同步：在你的 Mac 之间同步加密的密钥、名称、字段和备注，每台 Mac 单独批准调用方。默认关闭；历史缺值记录保留，不会用缺值覆盖另一台已有的值。
- 升级到新的受保护存储。首次从旧公开版升级时，请按引导确认本机迁移；原数据保留，调用方需要重新授权。全新安装使用独立的本机准备流程，同步由你另行开启。
- 同步暂时暂停后会自动恢复；修复启动时读取状态失败后，重试错误关闭同步，以及关闭后旧请求又重新开启的竞态。
- 重做欢迎引导、添加与编辑、详情、设置、网站登录态、使用权限和访问记录页面。支持 Codex／Claude Code 插件选择，自动生成的 ID 和环境变量与手填名称分开，授权详情可下钻。
- 修复 CLI 在 worktree 构建中版本显示 unknown，以及设置页误报已是最新的问题；优化中英文、窄分栏、输入框、过期提示和隐藏值预览。

**升级提示：** 从旧版迁移时可能出现 macOS 钥匙串授权，请核对请求来自 KeyKeeper。iCloud 同步需要同一 Apple 账号；网页登录态和调用方授权不会随云端同步。

## English

- Optional iCloud sync for encrypted keys and metadata across your Macs. Each Mac approves its own callers. Sync is off by default; missing-value records are retained without overwriting values present on another Mac.
- Protected local storage with an explicit migration flow for older installs. Original data is retained and callers require fresh approval. New installs have a separate local setup flow; enabling sync remains your choice.
- Automatic recovery after temporary sync interruptions. Fix retry incorrectly disabling sync at startup and a stale request re-enabling sync after it was turned off.
- Redesigned onboarding, add/edit, details, settings, website sessions, permissions and access history. Choose Codex or Claude Code setup, distinguish generated IDs from names you enter, and inspect authorization details.
- Correct CLI build versions in Git worktrees and unknown-version install status; improve localization, narrow split views, text fields, expiry indicators and masked value previews.

**Upgrading:** Confirm the local migration when prompted. macOS may ask for Keychain access from KeyKeeper. iCloud sync requires the same Apple account; website sessions and caller approvals remain local.
