# KeyKeeper 0.3.6

适用于 Apple Silicon Mac，macOS 14 或更新版本。

- **更新更及时**：运行时默认每 6 小时检查一次，签名更新在后台下载、退出时安装；一直不退出时，一天后会提醒。已保存的更新选择保持不变。
- **下载与安装说清楚**：设置开关改为“在后台下载更新”。关闭后依旧检查更新，但下载前会询问；不会为了安装更新突然中断当前工作。
- **Agent 调用更容易排错**：`keykeeper run --env` 支持精确映射变量名，`--plan` 可以预检映射与本地值是否存在，不读取密钥值、不启动目标命令。子命令失败时能分清是否已经完成注入。
- **首次使用与授权更清楚**：完善 Agent 的首次使用指引，并简化授权窗信息层次。
- **发布更可靠**：同时验证更新源与安装包的签名，核对线上文件的实际摘要；发布中断可安全续发，不覆盖已有不同版本，也不再把网络故障当作“版本不存在”。

更新依赖 KeyKeeper 正在运行和网络可用，不是实时推送。自动下载不等于立即安装；想马上更新，可以在设置里选择“检查更新…”。

---

For Apple Silicon Macs, macOS 14 or later.

- While running, KeyKeeper checks every six hours by default, downloads signed updates in the background and installs on quit. Long-running sessions get a reminder after a day. Explicit saved preferences are preserved.
- Settings now says “Download updates in the background,” distinguishing download from installation. Turning it off keeps checks and asks before downloading.
- `keykeeper run --env` maps fields to exact client variable names; `--plan` previews mappings and local presence without reading secret values or launching the child. Failure diagnostics distinguish successful injection from a failed child command.
- Clearer first-use guidance for agents and a simpler approval window.
- Release delivery validates both signatures and actual remote bytes. Interrupted releases resume without overwriting different assets or treating an unavailable service as an absent release.

Checks require the app to be running and a working connection; this is not push delivery. Use “Check for Updates…” to update sooner.
