# KeyKeeper 0.3.5

适用于 Apple Silicon Mac，macOS 14 或更新版本。

- **导入项目的 .env**：`keykeeper import ./.env --id my-app`。App 展示变量名，批准后全部值进入钥匙串，Agent 只收到结果；通过 `keykeeper run` 注入使用。原文件不删除，先验证项目跑通再自行清理。
- **113 个服务商模板**：按品牌、地区、套餐和凭据类型整理，支持搜索、分类、图标、有效期说明和官方后台跳转；新增凭据时可选模板。
- **Codex / Claude Code 双插件**：随 App 附带，设置里有安装指引；安装插件不等于授予密钥权限。
- **记录和权限可点开查看**：访问记录与名称/备注变更分开，详情展示调用方、授权范围和期限，历史结果不再冒充当前权限。
- **界面修复**：批准后刷新当前状态，展开/收起授权窗不再破坏边角；已有网站登录态也能继续选择 Chrome 导入或在 KeyKeeper 内登录。
- **浏览器导入可恢复**：CLI、接收页与 App 共用同一个提案状态。粘贴后即使错过弹窗或重启 App，也能在 10 分钟内从菜单面板继续审核，或用 `keykeeper proposal status/open` 查询和重新打开，不必再次复制密钥。
- **防止存错内容**：浏览器导入在写入前复核目标状态，终态会清除暂存值；字段可以持久保存“拒绝 URL”及公开前后缀规则，后续恢复和替换继续执行同一校验。
- **不再丢失待批准请求**：活跃请求会留在菜单面板中等待处理，历史决定与当前待办保持分离。

导入边界：仅支持单行赋值；保留引号中的转义内容，不执行变量/命令展开。格式不完整或多行值会拒绝整份导入；空值、保留变量和无法还原的变量名会列为跳过。所有导入值默认保密，不根据名字猜测可公开性。请先核对跳过项并验证项目，再删除原文件；导入不能撤回过去的泄漏。

许可证：App、CLI 与 Core 从本版起使用 FSL-1.1-MIT，两年后自动转为 MIT；SDK、skill 与插件继续使用 MIT，旧版本许可证不变。

---

For Apple Silicon Macs, macOS 14 or later.

- Import project dotenv files with native approval. Every imported value stays in the Keychain, credentials are inject-only, and the original file is retained.
- 113 provider templates with searchable brands/categories, region/plan distinctions, icons, expiry guidance and official console links.
- Bundled Codex and Claude Code plugins with setup instructions; installing a plugin grants no key access.
- Separate access/change histories and drill-down permission details. Historical decisions and current authorization are shown separately.
- Fix approval refresh, expanding/collapsing prompt corners, and missing Chrome import options after adding a website session.
- Browser imports now share one metadata-only proposal state across the CLI, receiver and App. After paste, a proposal remains recoverable for ten minutes, survives an App restart, and can be reviewed or cancelled from the menu panel without copying the secret again.
- Import commits re-check their target before writing and scrub held candidates at terminal states. Persistent URL rejection and public prefix/suffix rules protect later restores and replacements too.
- Live approval requests remain actionable in the menu panel when their original window is missed.

Import supports single-line assignments only, with quotes and escapes but no shell interpolation. Malformed/multiline input fails closed; empty, reserved or unsupported names are skipped. Validate your project and skipped variables before removing the original. Import does not undo previous exposure.

License: starting with this release, the app, CLI and core use FSL-1.1-MIT and convert to MIT after two years. The SDKs, skill and plugins remain MIT; earlier releases are unchanged.
